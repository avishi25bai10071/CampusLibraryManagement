# Campus Library Management System Using Java

## Problem Statement

Managing books, students, and book issue/return records manually in a college library can be time-consuming and may lead to errors.

The Campus Library Management System is developed to make these basic library activities easier to manage. The system provides a simple way to manage book and student information, issue and return books, maintain transaction records, and calculate fines for late returns.

---

## Scope of the Project

The project focuses on the basic management activities of a college library.

The scope includes:

- Adding and viewing books
- Searching for books
- Adding and viewing student information
- Issuing books to students
- Returning books
- Calculating fines for late returns
- Maintaining issue and return records
- Viewing a summary of library information
- Saving library data in text files
- Validating user input and handling errors

The project is designed as a simple menu-driven Java application and does not include online library services or database connectivity.

---

## Target Users

The main target users of this system are:

- **Librarian / Library Administrator** – to manage books, students, and issue/return activities.
- **Students** – their details and book borrowing records can be managed through the system.

---

## High-Level Features

- **Book Management** – Add, view, and search books.
- **Student Management** – Add and view student details.
- **Book Issue and Return** – Issue available books and record their return.
- **Fine Calculation** – Calculate fines for books returned after the allowed borrowing period.
- **Issue Records** – Maintain records of issued and returned books.
- **Library Summary** – Display total books, students, and currently issued books.
- **Input Validation** – Check user input and prevent invalid entries.
- **File Storage** – Save book, student, and transaction information in text files.
